# Class 2 — API Endpoints

| Folder | Role |
|---|---|
| [`api-endpoints/`](api-endpoints/) | Study lab (`code/`), homework, and SDD spec + `validate-lab` |
| [`api-endpoints-sdd/`](api-endpoints-sdd/) | Blank rebuild workspace — setup + data only, no answer key |
| [`instructor/`](instructor/) | Instructor-only run sheet + Phase 5 cheat prompt (not for students) |

**Flow:** run `api-endpoints/code/` → hand `api-endpoints/SDD/PROMPT.md` to your agent → build in `api-endpoints-sdd/` → score with `validate-lab` from `api-endpoints/SDD/`.
